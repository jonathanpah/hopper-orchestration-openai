# Release history / Histórico de releases

## 0.2.2 — 2026-10-03

- Restore the public verification summary in both language packages.
- Fix language-navigation links so each ZIP works independently.
- Synchronize version metadata and documented installation commands.
- Preserve orchestration rules, four roles, efforts `high`, `xhigh`, `max`,
  native invocation, and the deterministic helper.

An audit found different published and installed content labelled `0.2.1`.
This release identifies the corrected package with a new version. Identify
an artifact by its commit and SHA-256 as well as its version. Publish future
changes under a new version rather than replacing an existing tag or asset.

- Recupera o resumo público de verificação nos dois idiomas.
- Corrige a navegação entre idiomas para que cada ZIP seja autônomo.
- Sincroniza os metadados de versão e os comandos de instalação.
- Preserva regras, quatro papéis, esforços `high`, `xhigh`, `max`,
  acionamento nativo e auxiliar determinístico.

A auditoria encontrou conteúdos publicados e instalados diferentes com o
mesmo número `0.2.1`. Esta release identifica o pacote corrigido com uma
versão nova. Identifique artefatos também pelo commit e SHA-256. Publique
mudanças futuras em outra versão, sem substituir uma tag ou asset existente.
